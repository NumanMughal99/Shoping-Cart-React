🛒 Shopping Cart App

A shopping cart website UI built with React.js.

Features

- Home page with hero section
- Products page
- Shopping Cart page
- About page
- Contact page
- Reusable React components
- Colorful user interface

Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

How to Run

1. Clone this repository.

2. Open the project folder in VS Code.

3. Install dependencies:

   npm install

4. Start the project:

   npm run dev
